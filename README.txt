MetriX Train: deploy to GitHub Pages
1. Create a public GitHub repo (e.g. metrix-train).
2. Upload ALL files here, including the icons folder (Add file > Upload files).
3. Settings > Pages > Source: Deploy from branch, main, / (root). Save.
4. After a minute open https://YOURNAME.github.io/metrix-train/ in Android Chrome.
5. Menu (three dots) > Install app. Open it from the home screen.
Edit program.js to change exercises. After updating files, open Settings > Update app.
Back up often: Settings > Export backup.
